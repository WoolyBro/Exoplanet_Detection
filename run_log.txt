[2026-09-27 03:05] STAGE C CORRECTION - two defects found in a full-codebase review, both affecting the published table
  1. Scale-height mu. stage_b_level2.planet_parameters hardcoded mu = 2.3 (H2/He) for every planet, and Stage C
     reused its amplitude_1H_ppm as the `observable` component (weight 0.30) for all 54 planets, 21 of them rocky.
     For a rocky planet with a high-mu secondary atmosphere 2.3 is not doubtful but ruled out; stage_b_rocky_benchmark
     already used mu = 28 for the SAME planets. The two files disagreed by exactly 28/2.3 = 12.17x:
       GJ 1132 b  106.57 ppm (Stage C) vs 8.75 ppm (rocky benchmark);  LHS 475 b 75.51 vs 6.20;
       LHS 1140 b  43.44 vs 3.57;  GJ 486 b 49.61 vs 4.08.
     Fix: planet_parameters(planets, mu=...) now takes a scalar or a callable; the default stays 2.3 so Stage B
     Level 2 (13 H2/He planets) is untouched. Stage C assigns mu per planet: 28 below the 1.8 Re radius valley
     (Fulton+2017), 2.3 above. Both bracketing amplitudes are carried in the output as amplitude_1H_ppm_mu2p3/_mu28.
     Verified: the four overlapping planets now agree with the rocky benchmark to <0.05%.
  2. label_known. gas_scores() averaged every row of stage_b_lopo_predictions.csv, including the 136 of 265 rows
     Stage B masks out because the spectrum does not cover that molecule's band. That put numbers in cells Stage B

     Per-molecule coverage falls from 13/13/13 planets to H2O 11, CO2 8, CH4 9.
